## About the Project

Bedrock is an open-source & self-hostable alternative to Heroku / Netlify / Vercel / etc.

It helps you manage your servers, applications, and databases on your own hardware; you only need an SSH connection. You can manage VPS, Bare Metal, Raspberry PIs, and anything else.

Imagine having the ease of a cloud but with your own servers. That is **Bedrock**.

No vendor lock-in, which means that all the configurations for your applications/databases/etc are saved to your server. So, if you decide to stop using Bedrock (oh nooo), you could still manage your running resources. You lose the automations and all the magic. 🪄️

For more information, take a look at our landing page at [bedrock.io](https://bedrock.io).

## Installation

```bash
curl -fsSL https://cdn.bedrock.cloud/bedrock/install.sh | bash
```
You can find the installation script source [here](./scripts/install.sh).

## Cloud

If you do not want to self-host Bedrock, there is a paid cloud version available: [app.bedrock.io](https://app.bedrock.io)

For more information & pricing, take a look at our landing page [bedrock.io](https://bedrock.io).

## Why should I use the Cloud version?
The recommended way to use Bedrock is to have one server for Bedrock and one (or more) for the resources you are deploying. A server is around 4-5$/month.

By subscribing to the cloud version, you get the Bedrock server for the same price, but with:
- High-availability
- Free email notifications
- Better support
- Less maintenance for you

## 🇰🇪 Built for Kenya

Bedrock is specifically designed for the Kenyan market and emerging markets:

- **Local Data Sovereignty**: Your data stays in Kenya
- **Offline Capabilities**: Works during internet outages
- **Bandwidth Optimized**: Efficient for limited bandwidth
- **Power Resilient**: Handles unexpected shutdowns gracefully

## 🏗️ Architecture

Built on proven open-source foundations:
- **Core**: Based on Coolify (AGPL-3.0)
- **Container Runtime**: Docker
- **Database**: PostgreSQL
- **Reverse Proxy**: Caddy with automatic SSL

## 💰 Pricing

Pay once, deploy forever. No monthly surprises.

- **Free**: Open-source version
- **Pro**: KES 5,000/month ($40)
- **Lifetime**: KES 150,000 ($1,200)
